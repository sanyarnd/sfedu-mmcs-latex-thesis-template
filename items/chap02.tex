\section{Списки}

Есть три базовых окружения для списков.

Маркированный список:
\begin{itemize}
    \item первый пункт;
    \item второй пункт.
\end{itemize}

Нумерованный список:
\begin{enumerate}
    \item первый пункт;
    \item второй пункт.
\end{enumerate}

Список описаний:
\begin{description}
    \item[Термин] определение;
    \item[Другой термин] ещё одно определение.
\end{description}

Внешний вид списков настраивается пакетом \texttt{enumitem}. Глобальные
настройки шаблона (маркер~--- тире, без лишних отступов) заданы
в~\texttt{commands.tex} командой \verb+\setlist+. Для отдельного списка
параметры передаются в квадратных скобках:
\begin{enumerate}[label=\alph*)]
    \item пункт с буквенной нумерацией;
    \item ещё один пункт.
\end{enumerate}
