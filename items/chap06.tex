\section{Загрузка CSV файлов и построение графиков}

Данные экспериментов удобно хранить в CSV файлах (каталог \texttt{data/})
и строить по ним таблицы и графики прямо при компиляции. Тогда после
повторного запуска экспериментов достаточно заменить файлы с данными.

Если команда используется больше двух раз, её удобно оформить в виде макроса.

\newcommand{\timetable}[2]{%
    \DTLloaddb{data-#1}{\datapath/#1}%
    \begin{table}[H]
        \caption{#2}
        \setlength{\columnsep}{1.5cm}
        \setlength{\columnseprule}{0.2pt}
        \begin{multicols}{3}
            \begin{itemize}
                \DTLforeach{data-#1}{\blocksize=blockSize,\runtime=time}{%
                    \item[\blocksize] \qty{\runtime}{\milli\second}}
            \end{itemize}
        \end{multicols}
    \end{table}
}

\newcommand{\timechart}[3]{%
    \begin{figure}[H]
        \centering
        \begin{tikzpicture}
            \begin{axis}[
                    width        = 0.9\textwidth,
                    height       = 0.7\textwidth,
                    xlabel       = {Размер блока},
                    ylabel       = {Время, \unit{\milli\second}},
                    xmode        = log,
                    ymode        = log,
                    xtick        = {2, 4, 8, 16, 32, 64, 128, 256, 512, 1024},
                    xticklabels  = {2, 4, 8, 16, 32, 64, 128, 256, 512, 1024},
                    log ticks with fixed point,
                    grid         = major,
                    legend style = {at={(0.5,-0.2)}, anchor=north, draw=none},
                    legend columns = 2,
                    legend cell align = left,
                    mark size    = 1.5pt,
                ]
                \addplot table [x=blockSize, y=time, col sep=comma] {\datapath/#1_#2_omp_outer.csv};
                \addlegendentry{внешний \texttt{OpenMP}}

                \addplot table [x=blockSize, y=time, col sep=comma] {\datapath/#1_#2_omp_inner.csv};
                \addlegendentry{внутренний \texttt{OpenMP}}

                \addplot table [x=blockSize, y=time, col sep=comma] {\datapath/#1_#2_future.csv};
                \addlegendentry{\texttt{std::future}}

                \addplot table [x=blockSize, y=time, col sep=comma] {\datapath/#1_#2_seq.csv};
                \addlegendentry{последовательный}
            \end{axis}
        \end{tikzpicture}
        \caption{#3, тип \texttt{#2}}
    \end{figure}
}

Таблица строится пакетом \texttt{datatool}:
\timetable{gcc_int_seq.csv}{Время работы \texttt{GCC}, последовательный алгоритм, тип \texttt{int}}

График строится пакетом \texttt{pgfplots} (обе оси логарифмические):
\timechart{gcc}{int}{Время работы \texttt{GCC}}
