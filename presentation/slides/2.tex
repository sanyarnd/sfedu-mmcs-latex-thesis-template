\begin{frame}{Фильтр Винера}
    Фильтр минимизирует среднеквадратическое отклонение цвета пикселя:
    \[
        \hat{Y}(i, j) = \left[ \frac{\hat{H}^*(i, j)}{\left|\hat{H}(i, j)\right|^2
            + \frac{S_n(i, j)}{S_s(i, j)}} \right] \hat{F}(i, j),
    \]
    где
    \begin{itemize}
        \item $Y$~--- восстановленное изображение,
        \item $F$~--- наблюдаемое изображение,
        \item $H$~--- функция рассеяния точки, $H^*$~--- комплексное сопряжение $H$,
        \item $S_n = |\hat{N}|^2$~--- энергетический спектр шума,
        \item $S_s = |\hat{F}|^2$~--- энергетический спектр исходного изображения.
    \end{itemize}
\end{frame}
